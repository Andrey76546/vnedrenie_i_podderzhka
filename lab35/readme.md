🛠 Ход выполнения работы
1. Открытие терминала GNU/Linux

Для выполнения команд был открыт терминал операционной системы Ubuntu.

2. Определение текущего каталога
<img width="1124" height="661" alt="image" src="https://github.com/user-attachments/assets/d6e2f142-ff51-4689-a073-bbdfe72e2900" />

Для определения текущего рабочего каталога используется команда:

pwd

Команда pwd выводит полный путь к текущему рабочему каталогу.

Пример:

/home/user
3. Просмотр содержимого текущего каталога

Для просмотра списка файлов и каталогов используется команда:

ls

Команда выводит содержимое текущего каталога.

Для просмотра всех объектов, включая скрытые файлы, используется команда:

ls -a

Параметр -a позволяет отображать скрытые файлы и каталоги, имена которых начинаются с точки.

4. Смена текущего каталога

Для перехода между каталогами используется команда:

cd имя_каталога

Например:

cd /etc
<img width="1077" height="624" alt="image" src="https://github.com/user-attachments/assets/44ca5bd3-58f2-4946-8d64-82d7854905f6" />

Для перехода в домашний каталог пользователя:

cd ~

Для перехода на уровень выше:

cd ..
5. Создание нового каталога

Для создания каталога используется команда:

mkdir имя_каталога

Например:
<img width="1112" height="621" alt="image" src="https://github.com/user-attachments/assets/e8d96b28-9d1a-43cc-8b3f-6a75cbd2f3ad" />

mkdir new_dir

В результате был создан новый каталог:

new_dir
6. Удаление пустого каталога

Для удаления пустого каталога используется команда:

rmdir имя_каталога

Например:

rmdir new_dir

Команда удаляет только пустые каталоги.

7. Создание пустого файла

Для создания пустого файла используется команда:

touch имя_файла

Например:

touch newfile.txt

Также файл можно создать с помощью перенаправления вывода:

> имя_файла

Например:

> newfile.txt
8. Копирование файлов

Для копирования файлов используется команда:

cp источник назначение

Например:

cp file.txt copy.txt

В результате создаётся копия файла.

Для копирования каталога используется параметр -r:

cp -r каталог1 каталог2
9. Перемещение и переименование файлов

Для перемещения файлов используется команда:

mv источник назначение
<img width="1091" height="622" alt="image" src="https://github.com/user-attachments/assets/a923ed50-a4e1-42cc-a6f4-d98c6afab254" />

Например:

mv file.txt /tmp/

Эта же команда может использоваться для переименования файла:

mv oldname.txt newname.txt
10. Удаление файлов

Для удаления файла используется команда:

rm имя_файла

Например:

rm newfile.txt

Для удаления каталога вместе со всем его содержимым используется:

rm -r имя_каталога
11. Поиск файлов

Для поиска файлов используется команда:

find

Например, поиск файлов с расширением .txt:

find . -name "*.txt"
12. Использование шаблонов

Для работы с группами файлов можно использовать специальные символы.

Например:

ls *.txt

Команда выводит все файлы с расширением .txt.

Символ * обозначает любое количество символов.

13. Создание символической ссылки
<img width="1107" height="624" alt="image" src="https://github.com/user-attachments/assets/8cc82416-e0bc-44f3-8d51-6b8726a75d55" />

Для создания символической ссылки используется команда:

ln -s источник ссылка

Например:

ln -s file.txt link.txt

В результате создаётся символическая ссылка link.txt, указывающая на файл file.txt.

14. Оценка свободного дискового пространства

Для просмотра информации о занятом и свободном дисковом пространстве используется команда:

df -h

Команда отображает:

общий размер файловой системы;
использованное пространство;
доступное пространство;
процент использования;
точки монтирования.
